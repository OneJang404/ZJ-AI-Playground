# 文件夹自动整理机器人

一个简单易用的文件夹自动整理工具，可以自动监控指定文件夹，将新下载的文件按照类型分类到不同的子文件夹中。

## 功能特点
- ✅ 实时监控文件夹变化
- ✅ 自动识别文件类型并分类
- ✅ 支持自定义文件类型和分类规则
- ✅ 智能检测下载完成，避免移动未下载完的文件
- ✅ 图形化界面，操作简单
- ✅ 系统托盘运行，不占用桌面空间
- ✅ 开机自动启动
- ✅ 支持递归监控子文件夹

## 使用方法
1. 下载最新版本的exe文件
2. 双击运行
3. 选择你要监控的文件夹
4. 点击"立即整理全部"整理已有文件
5. 最小化窗口，程序会在后台自动运行
